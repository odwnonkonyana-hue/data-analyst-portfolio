# Part 3: GitHub Research

## 1. What types of accounts are available on GitHub?

GitHub offers personal accounts, organisation accounts and enterprise accounts. It also provides subscription plans such as Free, Pro, Team and Enterprise.

## 2. What can you do with a personal GitHub account?

A personal GitHub account allows users to create and manage repositories, upload and organise files, track changes, collaborate with others and showcase projects to potential employers.
